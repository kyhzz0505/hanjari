# 검색 결과 페이지

VS Code에서 frontend/index.html을 Live Server로 열고 검색하세요.
검색하면 results.html로 이동합니다. 결과 페이지 자체는 results.html을 우클릭해서 열어도 확인할 수 있습니다.
실제 목록과 사진은 localhost:8080의 기존 백엔드 및 DB가 실행되어 있어야 나타납니다.

## 파일
- results.html: 검색 조건, 왼쪽 필터, 식당 목록 영역
- results.css: 검색 결과 화면 및 스크롤을 따라오는 필터 스타일
- results.js: 검색 결과 API 연결, 좌석 필터, 정렬
- shared.js: 메인과 결과 화면에서 함께 쓰는 API, 알림, 상세 보기
- style.css: 메인과 결과가 공유하는 한지 배경, 색상, 헤더
- script.js: 메인 입력과 검색 결과 페이지 이동

## 동작
- 왼쪽 필터는 position: sticky를 사용해 화면 상단에서 24px 떨어진 위치를 유지하며 목록 안에서 따라옵니다.
- 룸, 일반 테이블, 연결 단체석을 선택하고 필터 적용을 누릅니다. 여러 종류를 고르면 그중 하나에 인원이 함께 앉을 수 있는 식당을 찾습니다.
- 필터 초기화는 인원·지역 조건을 유지하고 자리 형태 조건만 해제합니다.
- 넓은 자리 순은 식당의 최대 단체 수용 인원 기준입니다.
- 조건 바꾸기는 기존 인원·룸 조건을 메인에 전달합니다.
- AI 검색 결과는 추천 설명과 함께 표시합니다. 필터를 바꾸면 일반 조건 검색으로 전환합니다.
- 로그인·저장 안내는 상단, 검색 관련 안내는 하단에서 4초 후 0.6초 동안 흐려지며 사라집니다.

## 현재 데이터 범위
거리·가격·편의시설 데이터가 없어 해당 값을 만들어 표시하지 않습니다.
가까운 순은 안내를 표시하고, 별도 분류가 없는 좌식·전체 대관 필터는 비활성 상태입니다.
식당 상세는 실제 좌석 범위와 사진을 대화상자로 보여줍니다.
