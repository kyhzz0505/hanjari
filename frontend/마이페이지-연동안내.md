# 마이페이지 현재 상태

- `mypage.html`: 로그인한 사용자의 마이페이지. 로그인하지 않았으면 로그인 화면으로 이동했다가, 로그인 후 다시 돌아옵니다.
  (예전 `mypage-preview.html` 디자인을 그대로 쓰고, 예시 데이터 대신 실제 단골 목록을 보여 줍니다)
- `favorites.html`: `mypage.html#favorites`(마이페이지의 단골 목록)로 이동합니다.
- 로그인은 팀이 만든 체험 계정 1개로만 합니다. 회원가입은 없습니다. (API 명세 4번)
- 단골 목록은 서버에 저장됩니다. (API 명세 5번)
  - 검색 결과의 ♡를 누르면 단골에 추가, ♥를 다시 누르면 삭제
  - 로그인하지 않고 ♡를 누르면 로그인 화면으로 이동
  - 마이페이지의 ♥를 누르면 단골에서 삭제
- 최근 본 식당, 저장한 검색 조건, 프로필·개인정보 수정, 알림 설정은 "준비 중"으로 표시합니다.
- 로그인 여부는 서버(`GET /api/auth/me`)로 확인합니다. 브라우저 저장소의 표시만으로 개인 데이터 접근을 허용하지 않습니다.
