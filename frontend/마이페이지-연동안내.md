# 마이페이지 현재 상태

- `mypage-preview.html`: 로그인 후 화면의 디자인 미리보기. 개인 데이터가 아닌 공개 식당 예시만 표시합니다.
- `mypage.html`: 인증 API가 없는 현재 상태에서는 로그인 화면으로 이동합니다.
- 명칭은 단골 목록으로 통일했습니다. 화면의 프로필·집계 숫자는 사용자 데이터처럼 꾸며 넣지 않았습니다.
- 단골 추가 버튼은 기존 요청대로 로그인 안내 팝업만 표시합니다.

실제 로그인 후 화면으로 전환하려면 서버 인증 확인, 회원 프로필, 회원별 단골 목록 조회·추가·삭제 API가 필요합니다. API 명세가 확정되면 연결해야 하며, 브라우저 저장소의 로그인 표시만으로 개인 데이터 접근을 허용해서는 안 됩니다.

백엔드·DB는 이번 작업에서 변경하지 않았습니다.
